Micrositio de invitación para la fiesta del 15 de septiembre de 2026.

## Archivos

- `index.html` — contenido de la invitación.
- `style.css` — diseño y estilos.
- `script.js` — cuenta regresiva y animaciones.

## Publicar en GitHub Pages

1. Crea un repositorio nuevo en GitHub, por ejemplo: `invitacion-15-septiembre`.
2. Sube estos archivos a la rama `main`.
3. En GitHub entra a `Settings` → `Pages`.
4. En `Build and deployment`, selecciona `Deploy from a branch`.
5. Elige la rama `main` y la carpeta `/ (root)`.
6. Guarda y espera a que GitHub publique el sitio.

La invitación quedará disponible en:

`https://TU-USUARIO.github.io/invitacion-15-septiembre/`
